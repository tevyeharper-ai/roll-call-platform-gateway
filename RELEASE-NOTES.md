# F0.4.0 Release Notes

F0.4 moves Dream Kinetic: Forge from a foundation demo toward production infrastructure. It adds a PostgreSQL authority path, contractor invitation/access controls, repository verification, HTTPS readiness, stronger certification reporting, and a more explicit Lovable-like Prompt-to-Build Studio lifecycle while keeping publication separate from experimentation.

No claim is made that Prompt-to-Build generates production application code yet. That starts with F1.0 Data Builder after F0.4 infrastructure gates are live.
